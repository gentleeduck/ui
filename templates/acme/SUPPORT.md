# Support

Thanks for using **acme/ui**.

If you need help:

- Check our docs: [acme.com](https://www.acme.com)
- Join discussions: [GitHub Discussions](https://github.com/acme/acme-ui/discussions)
- Found a bug? [Open a Bug Report](https://github.com/acme/acme-ui/issues/new?template=bug_report.md)
- Have an idea? [Submit a Feature Request](https://github.com/acme/acme-ui/issues/new?template=feature_request.md)

Please **don't use GitHub Issues for support requests** — use Discussions or Chat instead.
