## Philosophy

Context menus are power-user shortcuts — they surface relevant actions where the user already is. We share the DropdownMenu component internals because the interaction pattern is identical; only the trigger mechanism (right-click vs button click) differs. This means you learn one API for both patterns.

## Behavior

- Right-click the trigger area to open the menu.
- Left-click does not open the menu; use DropdownMenu if you need click activation.
- Right-clicking outside closes the menu and allows the native browser menu to appear.

## API Reference

ContextMenu shares the same props as [DropdownMenu](/docs/components/dropdown-menu). Every ContextMenu sub-component is a thin wrapper around its DropdownMenu counterpart with `contextMenu` enabled by default. See the DropdownMenu API Reference for full prop details.

### ContextMenu

Root wrapper. Renders a `DropdownMenu` with `contextMenu` set to `true`.

*Accepts all `DropdownMenu` props.*

### ContextMenuTrigger

The right-click target area. Renders a `DropdownMenuTrigger` with default dimensions and dashed border styling.

*Accepts all `DropdownMenuTrigger` props.*

*Accepts all `DropdownMenuContent` props.*
