## Philosophy

Sliders let users select values within a range through direct manipulation. We build on Radix's accessible foundation (keyboard arrows, ARIA attributes, RTL support) and add the visual track/range/thumb styling. The Root/Track/Range/Thumb decomposition lets you restyle any part without rebuilding the interaction logic.

## API Reference

### Slider

A single-thumb slider. Internally composes `SliderPrimitive.Root`, `SliderPrimitive.Track`, `SliderPrimitive.Range`, and `SliderPrimitive.Thumb`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | -- | Additional CSS class names |

*Also accepts all `SliderPrimitive.Root` props (including `min`, `max`, `step`, `value`, `defaultValue`, `onValueChange`, `orientation`, `rtl`).*

### SliderRange

A dual-thumb range slider. Internally composes `SliderPrimitive.Root`, `SliderPrimitive.Track`, `SliderPrimitive.Range`, and two `SliderPrimitive.Thumb` elements (index 0 and 1).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | -- | Additional CSS class names |

*Also accepts all `SliderPrimitive.Root` props (including `min`, `max`, `step`, `value`, `defaultValue`, `onValueChange`, `orientation`, `rtl`).*

### Primitive Sub-components

The following primitives are used internally by `Slider` and `SliderRange`:

#### SliderPrimitive.Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `min` | `number` | `0` | Minimum allowed value |
| `max` | `number` | `100` | Maximum allowed value |
| `step` | `number` | `1` | Increment step for values |
| `value` | `number[]` | -- | Controlled values array (one or two values for range sliders) |
| `defaultValue` | `number[]` | `[50]` | Uncontrolled initial values |
| `onValueChange` | `(value: number[]) => void` | -- | Callback fired when slider values change |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Slider orientation |
| `rtl` | `boolean` | `false` | Enables right-to-left layout support |
| `...props` | `Omit<React.HTMLProps<HTMLDivElement>, 'defaultValue'>` | -- | Additional props to spread to the content div |

#### SliderPrimitive.Track

*Accepts all standard HTML `div` props.*

#### SliderPrimitive.Range

*Accepts all standard HTML `div` props.*

#### SliderPrimitive.Thumb

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `index` | `number` | (required) | The index of the thumb in the `values` array |
| `...props` | `React.HTMLProps<HTMLDivElement>` | -- | Additional props to spread to the content div |

### SliderContext & useSliderContext()

* **`SliderContext`**: React context providing slider state and methods:

  * `min`, `max`, `step`, `values`, `orientation`, `rtl`
  * `trackRef` -- Ref to track element.
  * `setValueAt(index, value)` -- Updates value for a specific thumb.
  * `positionToValue(pos, rect)` -- Converts pointer position to slider value.

* **`useSliderContext()`**: Hook for accessing `SliderContext`. Throws an error if used outside `SliderPrimitive.Root`.
