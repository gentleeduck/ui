## Philosophy

Alert dialogs are the nuclear option of UI interruption. Unlike regular dialogs, they can't be dismissed by clicking outside or pressing Escape -- the user must explicitly choose an action. Reserve them for destructive operations where an accidental dismissal could mean data loss.

## Usage

```tsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from '@/components/ui/alert-dialog';
import { Button } from '@/components/ui/button';
```

```tsx
<AlertDialog>
  <AlertDialogTrigger>Open</AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Are you absolutely sure?</AlertDialogTitle>
      <AlertDialogDescription>
        This action cannot be undone. This will permanently delete your account and remove your data from our servers.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction>Continue</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## API Reference

### AlertDialog

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultOpen` | `boolean` | `--` | Determines if the dialog should be open by default |
| `open` | `boolean` | `--` | Controls the visibility of the dialog |
| `onOpenChange` | `(open: boolean) => void` | `--` | Callback fired when the dialog opens or closes |
| `closeButton` | `boolean` | `true` | Whether to render the close button inside the content |
| `modal` | `boolean` | `--` | Whether the dialog is modal (locks interaction with the rest of the page) |
| `children` | `React.ReactNode` | (required) | Child elements (typically Trigger and Content) |

### AlertDialogTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | If `true`, renders using a `Slot` instead of a `button` element |
| `children` | `React.ReactNode` | `--` | Content of the trigger |
| `...props` | `React.HTMLProps<HTMLButtonElement>` | -- | Additional props to spread to the button element |

### AlertDialogCloseX

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `number` | `16` | Size in pixels for the close icon |
| `children` | `React.ReactNode` | `<X />` | Custom close icon; defaults to the `X` icon from lucide-react |
| `className` | `string` | `--` | Additional class names to apply |
| `...props` | `React.HTMLProps<HTMLButtonElement>` | -- | Additional props to spread to the button element |

### AlertDialogContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `--` | Additional class names to apply |
| `children` | `React.ReactNode` | `--` | Content displayed inside the dialog |
| `forceMount` | `boolean` | `false` | If `true`, forces the content to stay mounted in the DOM |
| `renderOnce` | `boolean` | `false` | If `true`, mounts content only once and preserves it |

*Also accepts all standard `AlertDialogPrimitive.Content` props.*

### AlertDialogHeader

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `--` | Additional class names to apply |
| `children` | `React.ReactNode` | `--` | Header content (typically Title and Description) |

*Also accepts all standard `AlertDialogPrimitive.Heading` props.*

### AlertDialogFooter

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `--` | Additional class names to apply |
| `children` | `React.ReactNode` | `--` | Footer content (typically Action and Cancel buttons) |
| `...props` | `React.HTMLProps<HTMLDivElement>` | -- | Additional props to spread to the content div |

### AlertDialogTitle

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `--` | Additional class names to apply |
| `children` | `React.ReactNode` | `--` | Title text content |

*Also accepts all standard `AlertDialogPrimitive.Title` props.*

### AlertDialogDescription

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `--` | Additional class names to apply |
| `children` | `React.ReactNode` | `--` | Description text content |

*Also accepts all standard `AlertDialogPrimitive.Description` props.*

### AlertDialogAction

Alias for `AlertDialogTrigger`. Accepts the same props.

### AlertDialogCancel

Alias for `AlertDialogTrigger`. Accepts the same props.
