## Philosophy

Native selects are accessible but unstyleable. Custom selects are styleable but inaccessible. We bridge this gap by wrapping Radix's Select primitive, which provides the keyboard interactions and ARIA roles that native selects get for free, while giving you full visual control over trigger, content, and items.

## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"
```

```tsx
<Select>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="Theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="light">Light</SelectItem>
    <SelectItem value="dark">Dark</SelectItem>
    <SelectItem value="system">System</SelectItem>
  </SelectContent>
</Select>
```

## API Reference

### Select

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | -- | Current selected value of the select component |
| `defaultValue` | `string` | `''` | Uncontrolled initial value |
| `onValueChange` | `(value: string) => void` | -- | Callback fired when the selected value changes |
| `scrollable` | `boolean` | `false` | Enables scroll buttons and makes the dropdown content scrollable |
| `contextMenu` | `boolean` | -- | Whether to render as a context menu |

*Also accepts all `Popover` props.*

### SelectWrapper

Internal component managing refs, selection state, and event handlers. Uses `SelectContext` to expose state and refs. Handles initialization of items and groups, manages highlighting and selection.

### SelectTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `customIndicator` | `React.ReactNode` | -- | Custom icon to display on the trigger instead of the default ChevronDown |
| `className` | `string` | -- | Additional CSS class names |
| `children` | `React.ReactNode` | -- | Trigger content |

*Also accepts all `PopoverTrigger` props.*

### SelectContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | -- | Additional CSS class names |
| `children` | `React.ReactNode` | -- | Content to render inside the dropdown |

*Also accepts all `PopoverContent` props.*

### SelectGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | -- | Additional CSS class names |
| `children` | `React.ReactNode` | -- | Group content (typically `SelectLabel` and `SelectItem` elements) |

*Also accepts all standard HTML `ul` props.*

### SelectValue

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `placeholder` | `string \| number` | -- | Text to show when no value is selected |
| `className` | `string` | -- | Additional CSS class names |
| `children` | `React.ReactNode` | -- | Custom content to render |

*Also accepts all standard HTML `div` props (except `placeholder`).*

### SelectLabel

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `htmlFor` | `string` | -- | ID of the associated input or control |
| `className` | `string` | -- | Additional CSS class names |
| `children` | `React.ReactNode` | -- | Label text content |

*Also accepts all standard HTML `label` props.*

### SelectItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | (required) | The value representing this item |
| `disabled` | `boolean` | -- | Whether the item is disabled |
| `className` | `string` | -- | Additional CSS class names |
| `children` | `React.ReactNode` | -- | Item content |

*Also accepts all standard HTML `li` props (except `value`).*

### SelectSeparator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | -- | Additional CSS class names |

*Also accepts all standard HTML `div` props.*

### SelectScrollUpButton / SelectScrollDownButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | -- | Additional CSS class names |

*Also accepts all `Button` props.*

### SelectContext

The context exposes:

| Property | Type | Description |
| --- | --- | --- |
| `open` | `boolean` | Dropdown open state |
| `value` | `string` | Current selected value |
| `triggerRef` | `React.RefObject<HTMLButtonElement \| null>` | Ref to the trigger button |
| `contentRef` | `React.RefObject<HTMLDivElement \| null>` | Ref to the scrollable dropdown content `<div>` |
| `groupsRef` | `React.RefObject<HTMLUListElement[] \| null>` | Ref to groups `<ul>` elements |
| `itemsRef` | `React.RefObject<HTMLLIElement[] \| null>` | Ref to the list of select items `<li>` |
| `selectedItem` | `HTMLLIElement \| null` | Currently selected item DOM element |
| `scrollable` | `boolean` | If the dropdown is scrollable |
