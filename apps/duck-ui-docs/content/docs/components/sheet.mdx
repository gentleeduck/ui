## Philosophy

Sheets are dialogs that slide in from the edge — they maintain spatial context better than centered modals. Use them for supplementary content (settings panels, detail views, mobile navigation) where the user needs to reference what's behind the overlay. The side prop makes the direction of information flow explicit.

### Usage

```tsx
import {
  Sheet,
  SheetContent,
  SheetDescription,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet"
```

```tsx
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Are you absolutely sure?</SheetTitle>
      <SheetDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

## Examples

### Side

Use the `side` property to `<SheetContent />` to indicate the edge of the screen where the component will appear. The values can be `top`, `right`, `bottom` or `left`.

<ComponentPreview name="sheet-2" />

### Size

You can adjust the size of the sheet using CSS classes:

```tsx {3}
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetContent className="w-[400px] sm:w-[540px]">
    <SheetHeader>
      <SheetTitle>Are you absolutely sure?</SheetTitle>
      <SheetDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

## API Reference

### Sheet

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `closeButton` | `boolean` | `true` | Whether to show the default close button on the sheet |

*Also accepts all `SheetPrimitive.Root` props.*

**Behavior:**
Renders the root container of the sheet dialog. Manages open/close state and displays the sheet overlay.

### SheetTrigger

*Accepts all `DialogTrigger` props.*

**Behavior:**
Renders the element that toggles the sheet open/close state. Acts as the trigger button or element.

### SheetContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `renderOnce` | `boolean` | `false` | Controls whether the content should only render once (currently unused) |
| `overlay` | `string` | `'default'` | Animation overlay style variant |
| `closedby` | `string` | `'any'` | Close behavior (currently unused) |
| `side` | `string` | `'right'` | The side from which the sheet slides in |

*Also accepts all `DialogContentProps & VariantProps<typeof AnimSheetVariants>` props.*

**Behavior:**
Renders the animated content area of the sheet with overlay and slide-in animations. Wraps children in a vertical flex container with spacing.

### SheetHeader

*Accepts all standard HTML `div` props.*

**Behavior:**
Renders a vertical flex container for the sheet header, typically used for titles or controls.

### SheetFooter

*Accepts all standard HTML `div` props.*

**Behavior:**
Renders a flex container for the sheet footer, stacked on small screens and horizontal with spacing on larger screens.

### SheetTitle

*Accepts all standard HTML `heading` props.*

**Behavior:**
Renders the heading/title element inside the sheet header.

### SheetDescription

*Accepts all standard HTML `p` props.*

**Behavior:**
Renders a description paragraph inside the sheet.

### SheetClose

*Accepts all `DialogClose` props.*

**Behavior:**
Renders a button that closes the sheet when clicked.
