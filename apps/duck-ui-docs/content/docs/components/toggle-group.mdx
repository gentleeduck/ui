## Philosophy

When multiple toggles share context, they become a group. ToggleGroup manages mutual exclusivity (single mode) or multi-selection, keeping the state logic out of your components. It's the same relationship as RadioGroup to Radio — the group owns the state, the items render the UI.

## API Reference

### ToggleGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `string` | `'default'` | Visual style variant for the toggles (passed down to items) |
| `size` | `string` | `--` | Size variant for the toggles (passed down to items) |
| `type` | `'single' \| 'multiple'` | `--` | Determines selection behavior. `'single'` allows only one toggle selected at a time; `'multiple'` allows multiple toggles selected |
| `onValueChange` | `(value: string) => void` | `--` | Callback invoked when a toggle item is selected or deselected |

*Also accepts all standard HTML `ul` props.*

### ToggleGroupItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `string` | `--` | Visual style variant for the toggle item |
| `size` | `string` | `--` | Size variant for the toggle item |
| `value` | `string` | (required) | The unique value identifying this toggle item |

*Also accepts all standard `Toggle.Toggle` props.*
