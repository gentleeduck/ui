## Philosophy

Hover cards provide progressive disclosure without commitment. They let users preview content before clicking, reducing unnecessary navigation. We build on Popover primitives because hover cards are fundamentally popovers with mouse-enter triggers — shared internals mean consistent behavior and smaller bundle size.

## Usage

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card"
```

```tsx
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent>
    The React Framework – created and maintained by @vercel.
  </HoverCardContent>
</HoverCard>
```

## API Reference

### HoverCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `skipDelayDuration` | `boolean` | `--` | Skip the delay duration before showing the card |
| `delayDuration` | `number` | `--` | Delay time in milliseconds before showing the card |
| `placement` | `string` | `'bottom'` | Position of the hover card relative to the trigger |

*Also accepts all standard `HoverCardPrimitive.Root` props.*

### HoverCardTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `string` | `'outline'` | Variant style applied to the internal button |
| `asChild` | `boolean` | `false` | Whether to use the child as the trigger element directly |

*Also accepts all standard `HoverCardPrimitive.Trigger` and `Button` props.*

### HoverCardContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `animation` | `string` | `'default'` | Animation variant controlling content appearance, from `AnimDialogVariants` |
| `overlay` | `string` | `'nothing'` | Overlay style variant from `AnimVariants` |

*Also accepts all standard `HoverCardPrimitive.Content` props.*
