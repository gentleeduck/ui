## About

Popover built with [@floating-ui/react](https://floating-ui.com/). Supports click, hover, and context menu triggers with smart placement.

## Philosophy

Popovers bridge the gap between tooltips (hover, no interaction) and dialogs (heavy, blocking). They're the right choice for inline forms, color pickers, and contextual actions that need more space than a tooltip but shouldn't interrupt the user's flow. We handle positioning and collision detection so you can focus on content.

## API Reference

### Popover

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultOpen` | `boolean` | `--` | Initial open state for uncontrolled usage |
| `open` | `boolean` | `--` | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | `--` | Callback when open state changes |
| `placement` | `Placement` | `'bottom'` | Placement relative to the trigger |
| `sideOffset` | `number` | `4` | Offset on the main axis |
| `alignOffset` | `number` | `0` | Offset on the cross axis |
| `mainAxis` | `boolean` | `true` | Enables main-axis flipping while positioning |
| `matchWidth` | `boolean` | `false` | Match the popover width to the trigger width |
| `enableHover` | `boolean` | `false` | Open on hover instead of click |
| `contextMenu` | `boolean` | `false` | Open on right-click at the cursor position |
| `modal` | `boolean` | `--` | Enables focus management when content is not disabled |

*Also accepts all standard `PopoverPrimitive.Root` props.*

### PopoverTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `--` | Use the child element as the trigger |

*Also accepts all standard `PopoverPrimitive.Trigger` props.*

### PopoverContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `forceMount` | `boolean` | `true` | Keep content mounted for CSS-driven animations |
| `lockScroll` | `boolean` | `false` | Locks scroll while the popover is open |
| `disabled` | `boolean` | `false` | Disables focus management when true |

*Also accepts all standard `PopoverPrimitive.Content` props.*

### PopoverClose

Alias for `PopoverTrigger`. Use to render an element that closes the popover.

*Accepts all `PopoverTrigger` props.*

### PopoverPortal

Renders the popover in a portal using Floating UI.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | `--` | Content to render inside the portal |

*Also accepts all `PopoverPrimitive.Portal` props.*
