## About

Popover built with [@floating-ui/react](https://floating-ui.com/). Supports click, hover, and context menu triggers with smart placement.

## API Reference

### **Popover**

* **`defaultOpen`** (`boolean`, optional): Initial open state for uncontrolled usage.
* **`open`** (`boolean`, optional): Controlled open state.
* **`onOpenChange`** (`(open: boolean) => void`, optional): Callback when open state changes.
* **`placement`** (`Placement`, optional, default: `'bottom'`): Placement relative to the trigger.
* **`sideOffset`** (`number`, optional, default: `4`): Offset on the main axis.
* **`alignOffset`** (`number`, optional, default: `0`): Offset on the cross axis.
* **`mainAxis`** (`boolean`, optional, default: `true`): Enables main-axis flipping while positioning.
* **`matchWidth`** (`boolean`, optional, default: `false`): Match the popover width to the trigger width.
* **`enableHover`** (`boolean`, optional, default: `false`): Open on hover instead of click.
* **`contextMenu`** (`boolean`, optional, default: `false`): Open on right-click at the cursor position.
* **`modal`** (`boolean`, optional): Enables focus management when content is not disabled.
* **`...props`** (`React.ComponentPropsWithRef<typeof PopoverPrimitive.Root>`): Additional props forwarded to the underlying popover root.

---

### **PopoverTrigger**

* **`asChild`** (`boolean`, optional): Use the child element as the trigger.
* **`...props`** (`React.ComponentPropsWithRef<typeof PopoverPrimitive.Trigger>`): Props forwarded to the trigger element.

---

### **PopoverContent**

* **`forceMount`** (`boolean`, optional, default: `true`): Keep content mounted for CSS-driven animations.
* **`lockScroll`** (`boolean`, optional, default: `false`): Locks scroll while the popover is open.
* **`disabled`** (`boolean`, optional, default: `true`): Disables focus management when true.
* **`...props`** (`React.ComponentPropsWithRef<typeof PopoverPrimitive.Content>`): Props forwarded to the content container.

**Behavior:**
`PopoverContent` receives `data-open` and `data-side` attributes for state-aware styling.

---

### **PopoverClose**

Alias for `PopoverTrigger`. Use to render an element that closes the popover.

---

### **PopoverPortal**

Renders the popover in a portal using Floating UI.
