## Philosophy

Dropdown menus are the Swiss Army knife of action UIs. They group related actions behind a single trigger, keeping interfaces clean while maintaining discoverability. Our implementation layers checkbox items, radio groups, sub-menus, and keyboard shortcuts into a composable system where each feature can be used independently.

## Usage

```tsx showLineNumbers
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"
```

```tsx showLineNumbers
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuLabel>My Account</DropdownMenuLabel>
    <DropdownMenuSeparator />
    <DropdownMenuItem>Profile</DropdownMenuItem>
    <DropdownMenuItem>Billing</DropdownMenuItem>
    <DropdownMenuItem>Team</DropdownMenuItem>
    <DropdownMenuItem>Subscription</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

## API Reference

### DropdownMenu

Root wrapper that provides dropdown state and context. Wraps Popover internally.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | `--` | Dropdown sub-components (`DropdownMenuTrigger`, `DropdownMenuContent`) |
| `defaultOpen` | `boolean` | `--` | Initial open state for uncontrolled usage |
| `open` | `boolean` | `--` | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | `--` | Callback when open state changes |
| `modal` | `boolean` | `false` | Enables modal focus/interaction behavior |
| `...props` | `React.ComponentPropsWithoutRef<typeof Popover>` | -- | Additional props inherited from `Popover`. |

### DropdownMenuTrigger

Button that toggles the dropdown menu open and closed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `--` | Use the child element as the trigger instead of wrapping in a button |
| `className` | `string` | `--` | Additional CSS classes to apply |
| `children` | `React.ReactNode` | `--` | Content rendered inside the trigger |
| `...props` | `React.ComponentPropsWithoutRef<typeof PopoverTrigger>` | -- | Additional props inherited from `PopoverTrigger`. |

### DropdownMenuContent

Container for the menu items. Rendered inside a portal.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `forceMount` | `boolean` | `--` | Keep content mounted for animation control |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'` | Preferred side relative to the trigger |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Alignment on the chosen side |
| `sideOffset` | `number` | `4` | Main-axis offset from trigger |
| `alignOffset` | `number` | `0` | Cross-axis offset from trigger |
| `...props` | `React.ComponentPropsWithoutRef<typeof PopoverContent>` | -- | Additional props inherited from `PopoverContent`. |

### DropdownMenuItem

An individual menu action item. Renders as a `Button` with `ghost` variant and `sm` size by default.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `inset` | `boolean` | `--` | Adds left padding to align with items that have icons |
| `disabled` | `boolean` | `--` | Prevents interaction and styles the item as disabled |
| `variant` | `'default' \| 'destructive' \| 'outline' \| 'secondary' \| 'ghost' \| 'link' \| 'dashed' \| 'warning' \| 'nothing' \| 'expand_icon'` | `'ghost'` | Visual variant of the button |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon' \| 'icon-sm' \| 'icon-lg'` | `'sm'` | Size of the button |
| `asChild` | `boolean` | `--` | Render as child component using Slot |
| `loading` | `boolean` | `--` | Shows a loading spinner |
| `icon` | `React.ReactNode` | `--` | Primary icon to display |
| `secondIcon` | `React.ReactNode` | `--` | Secondary icon |
| `...props` | `React.ComponentPropsWithoutRef<typeof Button>` | -- | Additional props inherited from `Button`. |

### DropdownMenuCheckboxItem

A menu item with a toggleable checkbox indicator.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | `--` | Controlled checked state |
| `onCheckedChange` | `(checked: boolean) => void` | `--` | Callback when checked state changes |
| `...props` | `React.ComponentPropsWithoutRef<typeof DropdownMenuItem>` | -- | Additional props inherited from `DropdownMenuItem`. |

### DropdownMenuRadioGroup

Groups radio items together for single-selection behavior.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | `--` | The currently selected radio value |
| `onValueChange` | `(value: string) => void` | `--` | Callback when the selected value changes |
| `defaultValue` | `string` | `--` | Initial value for uncontrolled usage |
| `...props` | `React.ComponentPropsWithoutRef<typeof RadioGroup>` | -- | Additional props inherited from `RadioGroup`. |

### DropdownMenuRadioItem

A radio-selectable menu item. Must be used inside `DropdownMenuRadioGroup`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | (required) | The value representing this radio item |
| `customIndicator` | `React.ReactNode` | `--` | Custom indicator element |
| `...props` | `React.ComponentPropsWithoutRef<typeof RadioGroupItem>` | -- | Additional props inherited from `RadioGroupItem`. |

### DropdownMenuLabel

A non-interactive label for grouping menu items.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `inset` | `boolean` | `--` | Adds left padding to align with inset menu items |
| `htmlFor` | `string` | `--` | Associates the label with a form control by its `id` |
| `className` | `string` | `--` | Additional CSS classes to apply |
| `...props` | `React.HTMLProps<HTMLLabelElement>` | -- | Additional props to spread to the label element |

### DropdownMenuSeparator

A visual divider between groups of menu items.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `--` | Additional CSS classes to apply |
| `...props` | `React.HTMLProps<HTMLDivElement>` | -- | Additional props to spread to the content div |

### DropdownMenuShortcut

Displays a keyboard shortcut hint next to a menu item and registers the key binding.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `keys` | `string` (optional) | -- | Keyboard shortcut string (e.g. `"ctrl+K"`) |
| `onKeysPressed` | `() => void` (optional) | -- | Callback invoked when the shortcut keys are pressed |
| `colored` | `boolean` | `false` | Applies a muted background to the shortcut badge |
| `...props` | `React.HTMLProps<HTMLElement>` | -- | Additional props to spread to the kbd element |

### DropdownMenuGroup

Groups related menu items together.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `--` | Additional CSS classes to apply |
| `children` | `React.ReactNode` | `--` | Menu items to render inside the group |
| `...props` | `React.HTMLProps<HTMLDivElement>` | -- | Additional props to spread to the content div |

### DropdownMenuSub

Wrapper for a submenu. Creates a nested popover with hover activation.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | `--` | Submenu trigger/content pair |
| `defaultOpen` | `boolean` | `--` | Initial open state for uncontrolled usage |
| `open` | `boolean` | `--` | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | `--` | Callback when open state changes |
| `modal` | `boolean` | `false` | Enables modal focus/interaction behavior |
| `...props` | `React.ComponentPropsWithoutRef<typeof Popover>` | -- | Additional props inherited from `Popover`. |

### DropdownMenuSubTrigger

Trigger element for a submenu. Displays a chevron icon indicating a nested menu.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `inset` | `boolean` | `false` | Adds left padding to align with inset menu items |
| `...props` | `React.ComponentPropsWithoutRef<typeof PopoverTrigger>` | -- | Additional props inherited from `PopoverTrigger`. |

### DropdownMenuSubContent

Content container for a submenu.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'right'` | Preferred side for the nested submenu |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Alignment on the chosen side |
| `sideOffset` | `number` | `4` | Main-axis offset from trigger |
| `alignOffset` | `number` | `0` | Cross-axis offset from trigger |
| `...props` | `React.ComponentPropsWithoutRef<typeof PopoverContent>` | -- | Additional props inherited from `PopoverContent`. |
