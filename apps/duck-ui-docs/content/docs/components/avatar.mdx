## Philosophy

Identity in UI starts with a face. Avatars humanize interfaces by giving users a visual anchor. We support both single avatars and groups because social context -- seeing who else is involved -- is a fundamental interaction pattern. The fallback-to-initials behavior ensures graceful degradation when images fail.

## API Reference

### Avatar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fallback` | `string` | `--` | Text displayed when the image fails to load; truncated to the first 2 characters |
| `alt` | `string` | `--` | Alternate text for the avatar image, also used as `aria-label` on the fallback |
| `className` | `string` | `--` | Additional class names for styling the avatar container |
| `ref` | `React.Ref<HTMLImageElement>` | `--` | Ref for the underlying `img` element |

*Also accepts all standard HTML `img` props.*

### AvatarGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `imgs` | `React.HTMLProps<HTMLImageElement>[]` | (required) | Array of props for each avatar image |
| `maxVisible` | `number` | `3` | Maximum number of avatars to display before showing overflow count |
| `className` | `string` | `--` | Additional class names for styling the avatar group container |
| `ref` | `React.Ref<HTMLDivElement>` | `--` | Ref for the container element |

*Also accepts all standard HTML `div` props.*
