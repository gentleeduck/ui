## Philosophy

Menubars bring desktop-application navigation patterns to the web. The keyboard model (arrow keys between menus, type-ahead search within items) follows established platform conventions because muscle memory matters more than novelty. We build on DropdownMenu internals so each menu panel gets the same rich feature set.

## API Reference

### Menubar

Root container that renders a horizontal bar and manages keyboard navigation across all menus. Provides `MenubarContext` for coordinating open state, trigger focus, and arrow-key movement between menus.

*Accepts all standard HTML `div` props.*

**Behavior:**
Handles `ArrowLeft`/`ArrowRight` keyboard navigation to move between menu triggers. When one menu is open, hovering over another trigger automatically switches to that menu.

### MenubarMenu

Wrapper for an individual menu within the menubar. Renders a `DropdownMenu` internally.

*Accepts all standard HTML `div` props (excluding `contextMenu`).*

### MenubarTrigger

Button that opens a specific menu in the menubar. Styled as a ghost button with `sm` size.

*Accepts all `DropdownMenuTrigger` props.*

### MenubarContent

*Accepts all `DropdownMenuContent` props.*

**Behavior:**
Registers a `keydown` listener for `ArrowUp`/`ArrowDown` item navigation and `ArrowLeft`/`ArrowRight` to switch between menubar menus from within an open dropdown.
