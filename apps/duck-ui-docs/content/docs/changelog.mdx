## February 2026

### Documentation Overhaul

This release is a comprehensive documentation rewrite covering every component and package page in duck-ui.

### JSON Editor Added (February 13, 2026)

Added a new `json-editor` component to the registry with examples and full docs coverage.

- Added `json-editor` to the UI registry with explicit dependency metadata:
  `@gentleduck/libs`, `react-hook-form`, `sonner`, and `lucide-react`.
- Added registry dependencies for installation order:
  `alert-dialog`, `button`, `popover`, `react-hook-form`, and `sheet`.
- Added `json-editor` examples to the registry examples package for inline/sheet mode, popover mode, and callback expand mode.
- Added full component docs at `/docs/components/json-editor` with installation, usage, examples, and API reference.
- Added a `JSON Editor` entry to docs sidebar navigation.

### API Props Coverage Update (February 13, 2026)

Completed a full API props normalization pass across component docs so inherited props are documented explicitly in API tables instead of prose notes.

- Replaced implicit "Accepts all ... props" and "Also accepts all ... props" notes with explicit `...props` rows in component API tables.
- Added missing `...props` rows for wrapper and composed components (including Context Menu, Dropdown Menu, Menubar, Popover, Drawer, Chart, React Hook Form, Resizable, and others).
- Standardized HTML `div` spread descriptions to "Additional props to spread to the content div" for consistency.
- Fixed malformed prop type references introduced during migration (notably Resizable panel types and FormLabel inherited props typing).

#### API Reference Tables

Every component page now includes a formal **API Reference** section with prop tables documenting types, defaults, and descriptions. This covers all 57 component pages:

Accordion, Alert, Alert Dialog, Aspect Ratio, Avatar, Badge, Breadcrumb, Button, Button Group, Calendar, Card, Carousel, Chart, Checkbox, Collapsible, Combobox, Command, Context Menu, Data Table, Date Picker, Dialog, Drawer, Dropdown Menu, Empty, Field, Hover Card, Input, Input Group, Input OTP, Item, Kbd, Label, Menubar, Navigation Menu, Pagination, Popover, Preview Panel, Progress, Radio Group, React Hook Form, Resizable, Scroll Area, Select, Separator, Sheet, Skeleton, Slider, Sonner, Switch, Table, Tabs, Textarea, Toggle, Toggle Group, Tooltip, Typography, and CVA.

#### Philosophy Sections

Every component and package page now has a **Philosophy** section explaining the design rationale -- why the component exists, what problem it solves, and the architectural decisions behind it.

#### Mermaid Diagrams

Two types of diagrams were added across 50+ pages:

- **Composition diagrams** -- Show how complex components nest sub-components (e.g., how `DropdownMenu` composes `Command`, `Popover`, `Button`, and `RadioGroup`).
- **"How It's Built" dependency diagrams** -- Show which internal packages (`@gentleduck/primitives`, `@gentleduck/variants`, `@gentleduck/motion`, `@gentleduck/libs`) and external libraries each component is built from.

Components with both diagram types include: Dialog, Sheet, Drawer, Command, Select, Combobox, Dropdown Menu, Tooltip, Popover, Button, Switch, Checkbox, Radio Group, Slider, Input OTP, Chart, Carousel, Calendar, Sonner, Resizable, React Hook Form, and more.

#### Callout Icons

All `<Callout>` blocks across the documentation now include contextual icons for better visual scanning -- warning triangles for accessibility notes, lightbulbs for tips, and bolt icons for package overviews.

#### Cross-Links

Related components now link to each other in their documentation. For example, Dialog links to Sheet and Drawer, Toggle links to Toggle Group, and Button links to Button Group.

All 9 core package pages now have structured documentation with architecture diagrams, philosophy sections, and API overviews:

- `@gentleduck/lazy` -- Lazy-loading utilities
- `@gentleduck/variants` -- Type-safe variant system (CVA wrapper)
