<Accordion type="multiple" className="w-full">
  <AccordionItem value="item-1">
    <AccordionTrigger>
      What makes @gentleduck/ui different from other UI libraries?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      @gentleduck/ui is built as part of a complete ecosystem, not just a collection of components.
      We've rewritten popular libraries to optimize performance, created custom primitives, and designed
      APIs that match familiar patterns from other frameworks.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-2">
    <AccordionTrigger>
      Is @gentleduck/ui just another UI clone?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      No. While inspired by modern UI libraries, Radix UI, and Fluent UI, @gentleduck/ui is built from scratch with
      its own primitives, utilities, and ecosystem. The primitives are headless and a11y-first, the variant
      system is custom, and the CLI scaffolds components into your project rather than hiding them in node_modules.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-3">
    <AccordionTrigger>
      Can I migrate from my current UI library?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      Our component APIs are designed to match patterns from popular libraries, so migration is
      incremental. Start by swapping one component at a time, or go all in. Both approaches work.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-4">
    <AccordionTrigger>
      How do I install and get started?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      Run <code className="bg-muted px-2 py-1 rounded">npx @gentleduck/cli init</code> to
      set up your project, then <code className="bg-muted px-2 py-1 rounded">npx @gentleduck/cli add button</code>
      (or any component name) to install specific components. Import and use them like any other React component.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-5">
    <AccordionTrigger>
      Is it production ready?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      It's used in production. Every component is optimized for performance, accessibility, and
      reliability. If something doesn't work, it gets fixed ASAP.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-6">
    <AccordionTrigger>
      How customizable are the components?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      Every component supports theme customization, style overrides, and composition patterns.
      Want to build your own components using our primitives? Go for it. Need to fork and modify something?
      Do it. Nothing is locked down.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-7">
    <AccordionTrigger>
      What about accessibility?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      Accessibility is baked in from day one. ARIA labels, keyboard navigation, screen reader support, 
      focus management - it's all there. We follow WCAG guidelines because shipping inaccessible products 
      in 2026 is inexcusable. Your users deserve better, and we make it easy to deliver.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-8">
    <AccordionTrigger>
      Does it work with TypeScript?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      Full TypeScript support with type definitions for all components. You get autocomplete, type
      checking, and IntelliSense that actually helps instead of getting in your way.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-9">
    <AccordionTrigger>
      How can I contribute or report issues?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">
      Head to our GitHub repository at{' '}
      <a href="https://github.com/gentleeduck/duck-ui" className="text-primary hover:underline">github.com/gentleeduck/duck-ui
      </a>. Report bugs, request features, submit pull requests, or improve documentation. We review 
      contributions quickly and actually respond. Good ideas get implemented, bad ideas get thoughtful 
      explanations. No corporate bureaucracy.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="item-10">

      What's the performance like?
    </AccordionTrigger>
    <AccordionContent className="text-muted-foreground">

      libraries for performance. Your components load quickly and stay responsive.

  </AccordionItem>
