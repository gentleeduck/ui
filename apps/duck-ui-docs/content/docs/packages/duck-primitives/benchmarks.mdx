## Why the difference

Radix ships each primitive as a **separate npm package** (`@radix-ui/react-dialog`, `@radix-ui/react-popover`, etc.). Each package bundles its own copy of shared internals:

- `@radix-ui/react-compose-refs` (~0.3 KB per package)
- `@radix-ui/react-context` (~0.4 KB per package)
- `@radix-ui/react-slot` (~0.8 KB per package)
- `@radix-ui/react-primitive` (~0.3 KB per package)
- `@radix-ui/react-use-callback-ref` (~0.2 KB per package)
- `@radix-ui/react-dismissable-layer` (~1.5 KB per package)
- `@radix-ui/react-focus-scope` (~1.5 KB per package)

When you install 5 Radix primitives, these internals are duplicated 5 times. With gentleduck, they're shared across all primitives from a single package.

## Methodology

- **gentleduck**: sizes measured from `packages/duck-primitives/dist/` by concatenating all `.js` files per primitive directory and running `gzip -c | wc -c`
- **Radix UI**: sizes from the [bundlephobia.com API](https://bundlephobia.com), queried per-package on 2026-03-22
- **Base UI / Ark UI / Headless UI**: entries left blank where bundlephobia data was unavailable or rate-limited. Only verified data is shown.
- All sizes are **minified + gzipped**
- Gentleduck `dist/` is built with tsdown (`minify: true`, `treeshake: true`, `format: 'esm'`)

To regenerate:

```bash
cd packages/duck-primitives
bun run benchmark
```

Output goes to `public/benchmarks/` and `apps/duck-ui-docs/public/images/benchmarks/primitives/`.
