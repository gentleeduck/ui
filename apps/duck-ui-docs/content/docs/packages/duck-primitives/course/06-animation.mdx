## The unmount problem

When a dialog closes, React removes its DOM nodes immediately. If you have a fade-out animation, you never see it because the element is gone before the animation starts.

<Callout icon={<Zap />}>

The `Presence` component solves this. It detects CSS animations on its child element and delays unmounting until `animationend` fires.

</Callout>

---

## Adding animations

All you need are CSS keyframes and `data-state` selectors. The primitives already apply `data-state` to Overlay and Content.

```css title="styles.css"
@keyframes overlayFadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
@keyframes overlayFadeOut {
  from { opacity: 1; }
  to { opacity: 0; }
}
@keyframes contentSlideIn {
  from { opacity: 0; transform: translate(-50%, -48%) scale(0.96); }
  to { opacity: 1; transform: translate(-50%, -50%) scale(1); }
}
@keyframes contentSlideOut {
  from { opacity: 1; transform: translate(-50%, -50%) scale(1); }
  to { opacity: 0; transform: translate(-50%, -48%) scale(0.96); }
}

.dialog-overlay[data-state="open"] { animation: overlayFadeIn 200ms ease; }
.dialog-overlay[data-state="closed"] { animation: overlayFadeOut 200ms ease; }
.dialog-content[data-state="open"] { animation: contentSlideIn 200ms ease; }
.dialog-content[data-state="closed"] { animation: contentSlideOut 150ms ease; }
```

```tsx
<Dialog.Portal>
  <Dialog.Overlay className="fixed inset-0 bg-black/50 dialog-overlay" />
  <Dialog.Content className="fixed top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 bg-white rounded-xl p-6 dialog-content">
    <Dialog.Title>Animated dialog</Dialog.Title>
    <Dialog.Close>Close</Dialog.Close>
  </Dialog.Content>
</Dialog.Portal>
```

Open and close the dialog. You will see both enter and exit animations play. Presence keeps the elements mounted during the exit animation.

## How Presence works internally

<Callout icon={<Lightbulb />}>

Presence uses a three-state machine:

1. **`mounted`** — element is in the DOM, visible.
2. **`unmountSuspended`** — `present` changed to `false`, but an exit animation is running. Element stays in DOM.
3. **`unmounted`** — animation finished. Element is removed from DOM.

</Callout>

When `present` changes from `true` to `false`, Presence reads `getComputedStyle(element).animationName` and compares it with the previous value. If it changed, an exit animation started, and Presence enters `unmountSuspended`. It then listens for `animationend` to transition to `unmounted`.

---

## Using Presence directly

You don't usually need to use Presence directly since primitives use it internally. But it's useful for custom components:

```tsx
import { Presence } from '@gentleduck/primitives/presence'

function Notification({ visible, children }) {
  return (
    <Presence present={visible}>
      <div className={`notification ${visible ? 'slide-in' : 'slide-out'}`}>
        {children}
      </div>
    </Presence>
  )
}
```

---

## The render function form

For more control over which classes to apply:

```tsx
<Presence present={isOpen}>
  {({ present }) => (
    <div className={present ? 'entering' : 'exiting'}>
      Content
    </div>
  )}
</Presence>
```

## The `forceMount` escape hatch

<Callout icon={<Target />}>

When you want to use a JS animation library (Framer Motion, React Spring) instead of CSS, use `forceMount` to keep elements always mounted.

</Callout>

```tsx
const [open, setOpen] = React.useState(false)

<Dialog.Root open={open} onOpenChange={setOpen}>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Portal forceMount>
    <AnimatePresence>
      {open && (
        <Dialog.Overlay forceMount asChild>
          <motion.div
            className="fixed inset-0 bg-black/50"
            initial={{ opacity: 0 }}
            animate={{ opacity: 1 }}
            exit={{ opacity: 0 }}
          />
        </Dialog.Overlay>
      )}
      {open && (
        <Dialog.Content forceMount asChild>
          <motion.div
            className="fixed top-1/2 left-1/2 bg-white rounded-xl p-6"
            initial={{ opacity: 0, y: 20, x: '-50%', translateY: '-50%' }}
            animate={{ opacity: 1, y: 0, x: '-50%', translateY: '-50%' }}
            exit={{ opacity: 0, y: 20 }}
          >
            <Dialog.Title>Framer Motion dialog</Dialog.Title>
            <Dialog.Close>Close</Dialog.Close>
          </motion.div>
        </Dialog.Content>
      )}
    </AnimatePresence>
  </Dialog.Portal>
</Dialog.Root>
```

## Reduced motion

<Callout icon={<TriangleAlert />}>

Always respect `prefers-reduced-motion` to provide a comfortable experience for users sensitive to animation.

</Callout>

```css
@media (prefers-reduced-motion: reduce) {
  .dialog-overlay,
  .dialog-content {
    animation: none !important;
  }
}
```
