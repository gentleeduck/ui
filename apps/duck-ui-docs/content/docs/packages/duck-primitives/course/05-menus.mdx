## Context menu

A right-click menu:

```tsx
import * as ContextMenu from '@gentleduck/primitives/context-menu'

function Canvas() {
  return (
    <ContextMenu.Root>
      <ContextMenu.Trigger className="w-80 h-48 border-2 border-dashed rounded-lg flex items-center justify-center text-gray-400">
        Right-click here
      </ContextMenu.Trigger>

      <ContextMenu.Portal>
        <ContextMenu.Content className="bg-white shadow-lg rounded-md p-1 min-w-[180px] border text-sm">
          <ContextMenu.Item className="px-3 py-1.5 rounded hover:bg-blue-50 cursor-pointer outline-none data-[highlighted]:bg-blue-50">
            Cut
          </ContextMenu.Item>
          <ContextMenu.Item className="px-3 py-1.5 rounded hover:bg-blue-50 cursor-pointer outline-none data-[highlighted]:bg-blue-50">
            Copy
          </ContextMenu.Item>
          <ContextMenu.Item className="px-3 py-1.5 rounded hover:bg-blue-50 cursor-pointer outline-none data-[highlighted]:bg-blue-50">
            Paste
          </ContextMenu.Item>
          <ContextMenu.Separator className="h-px bg-gray-200 my-1" />
          <ContextMenu.Item
            className="px-3 py-1.5 rounded text-red-600 hover:bg-red-50 cursor-pointer outline-none data-[highlighted]:bg-red-50"
            onSelect={() => console.log('deleted')}
          >
            Delete
          </ContextMenu.Item>
        </ContextMenu.Content>
      </ContextMenu.Portal>
    </ContextMenu.Root>
  )
}
```

Right-click the trigger area. The menu opens at the cursor position. Arrow keys navigate. <Kbd>Enter</Kbd> / <Kbd>Space</Kbd> activates.

## Menu item types

### Standard items

```tsx
<ContextMenu.Item onSelect={(event) => {
  console.log('Selected')
  // event.preventDefault() keeps the menu open
}}>
  Standard item
</ContextMenu.Item>
```

### Checkbox items

Toggle on/off with a visual indicator:

```tsx
const [showGrid, setShowGrid] = React.useState(true)

<ContextMenu.CheckboxItem
  checked={showGrid}
  onCheckedChange={setShowGrid}
  className="px-3 py-1.5 rounded flex items-center gap-2"
>
  <ContextMenu.ItemIndicator>
    <CheckIcon className="w-4 h-4" />
  </ContextMenu.ItemIndicator>
  Show grid
</ContextMenu.CheckboxItem>
```

### Radio items

Mutually exclusive choices:

```tsx
const [view, setView] = React.useState('grid')

<ContextMenu.RadioGroup value={view} onValueChange={setView}>
  <ContextMenu.RadioItem value="grid" className="px-3 py-1.5 rounded flex items-center gap-2">
    <ContextMenu.ItemIndicator>
      <DotIcon className="w-4 h-4" />
    </ContextMenu.ItemIndicator>
    Grid view
  </ContextMenu.RadioItem>
  <ContextMenu.RadioItem value="list" className="px-3 py-1.5 rounded flex items-center gap-2">
    <ContextMenu.ItemIndicator>
      <DotIcon className="w-4 h-4" />
    </ContextMenu.ItemIndicator>
    List view
  </ContextMenu.RadioItem>
</ContextMenu.RadioGroup>
```

## Submenus

Nested menus with hover/keyboard support:

```tsx
<ContextMenu.Sub>
  <ContextMenu.SubTrigger className="px-3 py-1.5 rounded flex justify-between items-center data-[highlighted]:bg-blue-50">
    Sort by
    <ChevronRight className="w-4 h-4" />
  </ContextMenu.SubTrigger>

  <ContextMenu.Portal>
    <ContextMenu.SubContent className="bg-white shadow-lg rounded-md p-1 min-w-[140px] border text-sm">
      <ContextMenu.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">Name</ContextMenu.Item>
      <ContextMenu.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">Date</ContextMenu.Item>
      <ContextMenu.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">Size</ContextMenu.Item>
    </ContextMenu.SubContent>
  </ContextMenu.Portal>
</ContextMenu.Sub>
```

<Kbd>ArrowRight</Kbd> opens the submenu. <Kbd>ArrowLeft</Kbd> closes it.

## Menubar

A horizontal bar of menus like a desktop app:

```tsx
import * as Menubar from '@gentleduck/primitives/menubar'

function AppMenubar() {
  return (
    <Menubar.Root className="flex gap-1 bg-white border rounded-lg p-1 shadow-sm">
      <Menubar.Menu>
        <Menubar.Trigger className="px-3 py-1 rounded text-sm hover:bg-gray-100 data-[state=open]:bg-gray-100">
          File
        </Menubar.Trigger>
        <Menubar.Portal>
          <Menubar.Content className="bg-white shadow-lg rounded-md p-1 min-w-[160px] border text-sm mt-1">
            <Menubar.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">New</Menubar.Item>
            <Menubar.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">Open</Menubar.Item>
            <Menubar.Separator className="h-px bg-gray-200 my-1" />
            <Menubar.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">Quit</Menubar.Item>
          </Menubar.Content>
        </Menubar.Portal>
      </Menubar.Menu>

      <Menubar.Menu>
        <Menubar.Trigger className="px-3 py-1 rounded text-sm hover:bg-gray-100 data-[state=open]:bg-gray-100">
          Edit
        </Menubar.Trigger>
        <Menubar.Portal>
          <Menubar.Content className="bg-white shadow-lg rounded-md p-1 min-w-[160px] border text-sm mt-1">
            <Menubar.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">Undo</Menubar.Item>
            <Menubar.Item className="px-3 py-1.5 rounded data-[highlighted]:bg-blue-50">Redo</Menubar.Item>
          </Menubar.Content>
        </Menubar.Portal>
      </Menubar.Menu>
    </Menubar.Root>
  )
}
```

<Callout icon={<Lightbulb />}>

Click "File" to open it. Then hover over "Edit" and it opens instantly. <Kbd>ArrowLeft</Kbd> / <Kbd>ArrowRight</Kbd> moves between menus.

</Callout>

## Keyboard navigation

All menu primitives implement WAI-ARIA menu keyboard patterns:

| Key | Action |
| --- | --- |
| <Kbd>ArrowDown</Kbd> | Next item |
| <Kbd>ArrowUp</Kbd> | Previous item |
| <Kbd>ArrowRight</Kbd> | Open submenu (on SubTrigger) / Next menu (Menubar) |
| <Kbd>ArrowLeft</Kbd> | Close submenu / Previous menu (Menubar) |
| <Kbd>Enter</Kbd> / <Kbd>Space</Kbd> | Activate highlighted item |
| <Kbd>Escape</Kbd> | Close menu |
| Type a character | Jump to item starting with that letter |

---

## The `data-highlighted` attribute

<Callout icon={<Lightbulb />}>

When an item is focused via keyboard or hovered, it gets `data-highlighted`. This is more reliable than `:hover` because it works for both mouse **and** keyboard navigation.

</Callout>

```css
.menu-item[data-highlighted] {
  background: #eff6ff;
}
```
