## The problem

Dialog.Trigger renders a `<button>`. But what if you want a link? Or a custom component from your design system? Without composition, you'd need a wrapper div or a forked component.

---

## The solution

Every primitive element supports `asChild`. When `true`, the primitive skips rendering its own element and passes all its props to the child element instead.

```tsx
// Default: renders a <button>
<Dialog.Trigger>Open</Dialog.Trigger>

// asChild: renders your <a> with Trigger's behavior
<Dialog.Trigger asChild>
  <a href="#">Open dialog</a>
</Dialog.Trigger>
```

The `<a>` now has `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls`, `data-state`, and the click handler. All merged from Dialog.Trigger.

---

## How prop merging works

When asChild is used, props merge with specific rules:

```tsx
<Dialog.Trigger asChild>
  <button
    className="my-class"
    style={{ color: 'red' }}
    onClick={() => console.log('child click')}
  >
    Open
  </button>
</Dialog.Trigger>
```

What happens:

- **Event handlers** compose: both Dialog.Trigger's `onClick` and your `onClick` fire. Your handler runs first.
- **`className`** concatenates: the child gets both the primitive's and your class names.
- **`style`** merges: your styles override the primitive's for conflicting properties.
- **`ref`** composes: both refs receive the DOM element.
- **Other props**: child props override primitive props.

## Using with custom components

<Callout icon={<TriangleAlert />}>

Your component **must** forward refs. If it doesn't, `asChild` silently breaks. Always use `React.forwardRef` for components that will be used with primitives.

</Callout>

```tsx
const FancyButton = React.forwardRef<HTMLButtonElement, React.ButtonHTMLAttributes<HTMLButtonElement>>(
  (props, ref) => (
    <button ref={ref} {...props} className={`fancy-button ${props.className || ''}`} />
  )
)

// Now it works with asChild
<Dialog.Trigger asChild>
  <FancyButton>Open</FancyButton>
</Dialog.Trigger>
```

## Common patterns

### Icon button close

```tsx
<Dialog.Close asChild>
  <button aria-label="Close dialog" className="absolute top-3 right-3 p-1 rounded-full hover:bg-gray-100">
    <XIcon className="w-4 h-4" />
  </button>
</Dialog.Close>
```

### Tooltip on a link

```tsx
<Tooltip.Trigger asChild>
  <a href="/docs">Documentation</a>
</Tooltip.Trigger>
```

### Popover with custom anchor

```tsx
<Popover.Trigger asChild>
  <div className="inline-flex items-center gap-2 cursor-pointer">
    <Avatar src={user.avatar} />
    <ChevronDown className="w-4 h-4" />
  </div>
</Popover.Trigger>
```

---

## The rule

<Callout icon={<TriangleAlert />}>

`asChild` requires **exactly one** child element. Multiple children will cause an error.

</Callout>

```tsx
// Error: multiple children
<Dialog.Trigger asChild>
  <span>Icon</span>
  <span>Text</span>
</Dialog.Trigger>

// Fix: wrap in a single element
<Dialog.Trigger asChild>
  <button>
    <span>Icon</span>
    <span>Text</span>
  </button>
</Dialog.Trigger>
```

---

## Under the hood: Slot

`asChild` is powered by the `Slot` component. When `asChild` is true, the primitive renders a `Slot` instead of the native element. Slot clones the child element with merged props. You can use `Slot` directly when building your own primitives:

```tsx
import { Slot } from '@gentleduck/primitives/slot'

function MyComponent({ asChild, ...props }) {
  const Comp = asChild ? Slot : 'button'
  return <Comp {...props} />
}
```
