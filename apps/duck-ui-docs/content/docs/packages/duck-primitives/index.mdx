## What is gentleduck/primitives?

gentleduck/primitives is a collection of low-level, unstyled React components that handle behavior and accessibility so you can focus on design. Each primitive manages the hard parts (focus trapping, keyboard navigation, ARIA attributes, dismiss-on-click-outside, scroll locking) and gives you full control over rendering and styling.

Think of them as the behavioral atoms of a design system. They handle the "how it works" so you define the "how it looks."

---

## Why gentleduck/primitives?

Building accessible UI components from scratch is hard. A dialog needs focus trapping, escape-to-close, scroll locking, ARIA labeling, and animation-aware mounting. A popover needs positioning, click-outside dismissal, and focus management. Getting all of this right across browsers and screen readers is hundreds of hours of work.

gentleduck/primitives gives you production-ready behavior out of the box:

- **Accessible by default.** Correct ARIA roles, labels, and keyboard interactions.
- **Unstyled.** Zero CSS opinions. Bring your own styles, Tailwind, CSS modules, whatever.
- **Composable.** Every component supports `asChild` for full rendering control.
- **Controlled or uncontrolled.** All state can be managed by you or by the component.
- **Animation-aware.** The `Presence` system waits for CSS animations before unmounting.

## Architecture

<MermaidDiagram chart={`graph TD
    PE[Primitive Elements] --> SL[Slot]
    SL --> DL[Dismissable Layer]
    SL --> FS[Focus Scope]
    SL --> PR[Presence]
    SL --> PO[Portal]
    SL --> PP[Popper]
    DL --> DI[Dialog]
    FS --> DI
    PR --> DI
    PO --> DI
    DI --> AD[Alert Dialog]
    PP --> POP[Popover]
    PP --> TT[Tooltip]
    PP --> HC[Hover Card]
    PP --> MN[Menu]
    MN --> CM[Context Menu]
    MN --> DM[Dropdown Menu]
    MN --> MB[Menubar]
    MN --> NM[Navigation Menu]
    PE --> PG[Progress]
    PE --> PN[Pagination]
    PP --> SEL[Select]
    PE --> RG[Radio Group]
    PE --> SLD[Slider]
`} />

Higher-level primitives compose lower-level ones. Dialog uses Dismissable Layer, Focus Scope, Presence, and Portal. Menu uses Popper for positioning. You can use any layer directly.
