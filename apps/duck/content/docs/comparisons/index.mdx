## How gentleduck/ui compares

Every claim on these pages is backed by verified data: bundle sizes measured from built dist output, Radix sizes from bundlephobia.com, feature comparisons verified against actual source code. We include cases where competitors win.

### vs shadcn/ui

Same copy-paste philosophy. Same component names. Same Tailwind approach. The difference: gentleduck ships its own primitives (50-92% smaller than Radix), a calendar engine (5 KB vs 20 KB), a keyboard command system, animation tokens, and a CLI that can update, remove, and diff components. shadcn ecosystem templates work with gentleduck - swap the base imports and everything stays the same.

[**Full comparison with code examples and migration guide**](/docs/comparisons/vs-shadcn)

### vs Radix UI

Same compound-component API. Same asChild pattern. Same data-state attributes. gentleduck primitives are 50-92% smaller because shared internals load once instead of being duplicated per-package. Alert Dialog: 1.6 KB vs 18.6 KB. Popover: 2.4 KB vs 19.6 KB. Migration is a namespace change in your imports.

[**Full comparison with bundle size charts**](/docs/comparisons/vs-radix)

### vs react-day-picker

4 calendar systems at 5 KB vs 1 calendar system at 20 KB. Zero dependencies vs date-fns lock-in. 7 pluggable date adapters. Headless useCalendar hook for custom UIs. The only copy-paste calendar library with Islamic, Persian, and Hebrew support.

[**Full comparison with migration guide**](/docs/comparisons/vs-react-day-picker)
