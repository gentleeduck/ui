## Latest - April 2026

Imported gen, query, iam, ttest, and upload from sibling repos. Per-package velite collections + buildSidebar helper. Build memory rewritten so Netlify stops SIGKILLing. `/docs/*` retired in favor of `/www/*`. Org-wide www docs rewrite. Slot className merge fix released as primitives 0.2.11.
