## Advanced Table System <Badge>feat</Badge>

Rebuilt the table layer from scratch around a header-first, column-driven model:

- New header shape with grouped columns and resize affordances.
- Mountable row actions — Sheet/Dialog editors that survive table re-renders without unmounting the open editor.
- Refactored `DropdownMenu` to compose with the new advanced table actions.
- Moved table animations and toggle states off ad-hoc CSS into Tailwind classes.

The foundation that ships through the rest of 2025 starts here.

---

## Benchmark Package — SIGMA <Badge>feat</Badge>

Initialized `@gentleduck/benchmark`, the harness for comparing the duck components against shadcn/Radix equivalents:

- Project skeleton and config to host per-component benchmark apps.
- First subject: `Button`. Native Tailwind button, shadcn button, and duck button measured side by side.
- React Scan integration so unintended re-renders show up loudly in the harness output.
- Path resolution wired so the benchmark imports the registry source directly without rebuilding.

## Monorepo Cleanup <Badge variant="outline">refactor</Badge>

- Centralized every registry into a single repo location instead of scattered per-app copies.
- Removed legacy build artifacts and dead config files.
- Tidied cross-package imports so the registry builder and the docs site agree on resolution.
- Fixed the long-standing build break — every package now compiles in one pass.
