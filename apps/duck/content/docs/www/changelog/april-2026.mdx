The most disruptive month so far this year. Five new packages joined the workspace, the docs site moved to per-package velite collections, the production build memory profile was rewritten end-to-end, the `/docs/*` URL space was retired in favor of `/www/*`, and the marketing surface was rewritten to speak for the whole organization instead of the UI library alone.

## Workspace Reorganization <Badge variant="outline">refactor</Badge>

- Moved unfinished packages under `packages/wip/` and end-of-life packages under `packages/deprecated/`.
- Removed the legacy `_oldstuff_refactor` directory.
- Aligned the Vite catalog across every package; Biome now ignores `wip/` and `deprecated/`.
- Refreshed the registry build output to drop archived imports.

## Package Migration <Badge>feat</Badge>

Imported five packages from sibling repos into the monorepo:

- [`@gentleduck/gen`](/duck-gen) — code generation for controllers, routes, and schemas.
- [`@gentleduck/query`](/duck-query) — typed query helpers for the data layer.
- [`@gentleduck/iam`](/duck-iam) — identity, RBAC, sessions, audit.
- [`@gentleduck/ttest`](/duck-ttest) — type-aware test runner.
- [`@gentleduck/upload`](/duck-upload) — resumable upload pipeline.

Every package landed with its existing changelog, tests, and docs. CI now builds and tests them in the same pipeline as the rest of the workspace.

## Marketing Surface <Badge>feat</Badge>

- Unified the marketing home pattern across every package route. Each package landing page now shares the same hero, feature grid, install snippet, and footer rhythm.
- Rewrote prose on every package MDX (calendar, gen, iam, primitives, query, registry-build, ttlog, upload, vim, ui, comparisons, mcp) to drop benchmark-speak and read like a human.

## Lifecycle Badges <Badge>feat</Badge>

Added a lifecycle badge metadata field to every package. The badge surfaces on:

- Each package landing page.
- The shared docs navigation.
- The MDX header for every page in a package.

Badges differentiate `stable`, `beta`, `experimental`, and `deprecated` packages so consumers can read the maturity at a glance.

## Documentation Pipeline <Badge variant="outline">refactor</Badge>

- Split velite from one global `docs` collection into per-package collections (`duckUi`, `duckPrimitives`, `duckCalendar`, …). Each route loads only its own collection.
- Added a `buildSidebar` helper in [`@gentleduck/docs`](/duck-docs) so per-package routes get grouped sidebars without a hand-written config.
- Migrated every slug page to its package-scoped collection. Dropped the now-redundant top-level config and packages exports.
- Frontmatter on every package MDX now declares `section` and `order` for the grouped sidebar.

## LLM-friendly Docs <Badge>feat</Badge>

New `/llm/[slug]` route that serves the pre-rendered markdown for any docs page directly from velite. Designed for AI agents that want raw text without the surrounding chrome.

## Build Performance <Badge variant="outline">perf</Badge>

The production build was OOM'ing on Netlify's 8 GB sandbox. Two passes fixed it:

- **First pass.** Scoped the root `docs` collection so per-package MDX wasn't duplicated into a 60 MB `docs.json`. Capped Next's page-data workers at 4 (`experimental.cpus`, `workerThreads: false`). Disabled production browser source maps. Pinned `NODE_OPTIONS=--max-old-space-size=6144` in `netlify.toml`.
- **Second pass.** Switched the production build off Turbopack (Next 16 default) back to webpack via `--webpack`, which uses ~30% less RAM on this MDX graph. Lifted `NODE_OPTIONS` to 7168 MB for headroom.

Velite output dropped from 112 MB to 39 MB. Netlify build no longer SIGKILLs.

## Route Refactor — /docs → /www <Badge variant="outline">refactor</Badge>

- Removed the `/docs/[[...slug]]` route entirely.
- New `/www/[[...slug]]` route serves the `www` velite collection.
- Migrated `introduction`, `installation`, `packages`, `faqs`, `changelog`, `comparisons`, and `dark-theme` content under `apps/duck/content/docs/www/`.
- Rewrote internal `/docs/*` MDX links to `/www/*`.
- Home + CTA section CTAs point at `/www/installation` and `/www/packages`.

## Sidebar Cleanups <Badge variant="outline">fix</Badge>

- Sidebar groups no longer collapse — `collapsibleThreshold` removed from the builder option type, default, and config.
- Sidebar hrefs now strip trailing `/index` so canonical URLs (e.g. `/www/changelog`) match what `[[...slug]]` resolves.
