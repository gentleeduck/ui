The single biggest month of 2025 so far. The codebase moved from `@duck` to `@gentleduck`, Tailwind 4 landed, the first CLI prototype shipped, the docs MDX components took their final shape, and roughly twenty components were benchmarked side-by-side against shadcn/Radix.

## Scope rename — @duck → @gentleduck <Badge variant="outline">refactor</Badge>

Renamed every workspace package from `@duck/*` to `@gentleduck/*`. All public packages now ship under the `@gentleduck` npm scope. Imports across docs, registry, examples, and benchmarks were updated in the same pass.

---

## Tailwind 4 <Badge>feat</Badge>

Upgraded the entire registry to Tailwind 4:

- New `@theme` token model adopted across components.
- `tailwindcss-animate` replaced with native CSS-based variants.
- Migrated colors and radii to OKLCH-friendly token shapes.
- Verified Lighthouse a11y scores stayed at 100 across docs pages after the upgrade.

---

## @gentleduck/lazy <Badge>feat</Badge>

Published [`@gentleduck/lazy`](/duck-lazy) — an intersection-observer-based lazy mounting primitive for React.

- `useLazy` hook exposes the lifecycle for custom integrations.
- Configurable threshold and rootMargin.
- Next.js compatible (no SSR-only globals).
- First package to go through the changesets release flow.

---

## CLI Prototype — duckui-cli <Badge>feat</Badge>

First public-facing pieces of what becomes [`@gentleduck/cli`](/duck-cli) in October:

- `init` flow with TypeScript preflight and `duck-ui.config` generation.
- Preflight checks for `tsconfig.json`, `package.json`, and registry availability.
- First pass at `add` — fetching components from the registry and writing them into the project.
- Resolved alias mismatches between `duck-ui.config` and `tsconfig.json` paths.

---

## Documentation Site <Badge>feat</Badge>

The MDX layer reached its current shape:

- `<ComponentPreview>` and `<ComponentSource>` blocks render previews next to copy-paste sources.
- Velite pipeline finalized for code-block rehyping (treesitter highlighting + copy button).
- Sidebar visual refresh — sticky, scroll-locked, and keyboard-navigable.
- Tailwind indicator overlay for development.
- Robots.txt + per-page metadata + image `alt` attributes for SEO and accessibility.
- Performance pass on font loading (adjusted font faces, font-display tuning).

## Benchmarks <Badge>feat</Badge>

Subject components added to the benchmark harness this month:

`Badge`, `Label`, `Checkbox`, `Switch`, `RadioGroup`, `Input`, `ScrollArea`, `HoverCard`, `Slider`, `Accordion`, `Progress`, `Select`, `Separator`, `Skeleton`, `Sheet`, `Drawer`, `Sonner`, `Tabs`.

Across the board the duck components matched or beat shadcn equivalents on both bundle size and re-render count.

## Other fixes

- Dialog: removed unused animation classes; cleaned hover/scroll behavior across nav components.
- `ScrollArea`: switched to native CSS scroll for measurably better performance.
- Build: resolved type errors in `CopyButton` and `velite.config`.
- Theme template: removed redundant whitespace from generated CSS.
