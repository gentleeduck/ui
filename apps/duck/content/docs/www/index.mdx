## What gentleduck is

`gentleduck` is an open-source organization that ships a connected set of TypeScript packages for building production React applications. Every package is independently versioned and useful on its own — but they were designed together, so adopting more of them keeps adding leverage instead of complexity.

The ecosystem covers what real products actually need: a styled UI layer, the headless primitives underneath it, a calendar engine that handles non-Gregorian dates, a keyboard command engine, a CLI that goes beyond `add`, and a server-side surface for identity, uploads, queries, and code generation.

## What you can build with it

- **A new product UI** — start with [duck-ui](/duck-ui) for styled components and the [CLI](/duck-cli) to scaffold them into your codebase.
- **An accessible component library** — drop down to [duck-primitives](/duck-primitives) and bring your own design system on top.
- **A globally aware date picker** — [duck-calendar](/duck-calendar) supports Islamic, Persian, Hebrew, Buddhist, Indian, and Japanese calendars alongside Gregorian.
- **A keyboard-first interface** — [duck-vim](/duck-vim) gives you chord matching, key sequences, and a recorder with React hooks.
- **A custom registry** — [duck-registry-build](/duck-registry-build) lets you publish your own component registry that the CLI can install from.
- **A full-stack feature** — pair [duck-iam](/duck-iam) for auth, [duck-upload](/duck-upload) for ingest, [duck-query](/duck-query) for typed data access, and [duck-gen](/duck-gen) for the codegen glue.

## Open source

`gentleduck` is MIT-licensed. Source lives on GitHub at [github.com/gentleeduck/duck-ui](https://github.com/gentleeduck/duck-ui). Issues, pull requests, and discussions are open. The project is maintained by a small team — sponsorship and contributions both directly extend the time available to keep the ecosystem moving.
