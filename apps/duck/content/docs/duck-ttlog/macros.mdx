The `ttlog-macros` crate provides the user-facing logging API. The procedural macros move as much work as possible to compile time.

## Available Macros

The crate provides a macro for each standard log level:

- `trace!`
- `debug!`
- `info!`
- `warn!`
- `error!`
- `fatal!`

## Usage

### 1. Message Only

Equivalent to `println!`.

```rust
use ttlog_macros::info;

info!("User successfully authenticated.");
```

### 2. Message with Structured Data (Key-Value Pairs)

Add context with `key = value` syntax. The message string is the last string literal in the argument list.

```rust
use ttlog_macros::warn;

let user_id = 123;
let attempt_count = 3;
warn!(user_id = user_id, attempts = attempt_count, "Failed login attempt");
```

### 3. Structured Data Only

Key-value pairs without a message.

```rust
use ttlog_macros::debug;

let db_latency_ms = 55;
let query = "SELECT * FROM users";
debug!(latency = db_latency_ms, query = query);
```

### 4. Event-Only Logging

Log an occurrence with no message or data.

```rust
use ttlog_macros::trace;

trace!("Entering critical section");
// ... some code ...
trace!(); // Log that we've entered the section
```

## How It Works

The macros do more than rewrite syntax. They push work to compile time.

1. **Static string interning**: The macros parse log arguments at compile time. The message string and key names are known, so the macro generates code that interns them once per application lifetime using `std::sync::OnceLock`. Subsequent calls to the same log statement are integer lookups.

2. **Static metadata**: File path, module path, and line number are captured at compile time via `file!()`, `module_path!()`, and `line!()`. No runtime gathering.

3. **Value serialization**: Key-value pairs serialize to a compact binary format. Primitive integer types (`i64`, `u64`) and floating-point types (`f32`, `f64`) are converted to strings directly, not through `serde`.

4. **Direct logger call**: The expanded code calls into the `ttlog` crate's `GLOBAL_LOGGER` without intermediate abstraction.

A call to `info!` expands to a block of code tailored to the arguments you passed.
