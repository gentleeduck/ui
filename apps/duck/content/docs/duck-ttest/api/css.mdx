Sized intentionally to avoid blowing up the type-checker. Use for component props that want autocomplete on CSS-shaped strings.

## Wide-keyword values

```ts
type CSSGlobal = 'inherit' | 'initial' | 'unset' | 'revert' | 'revert-layer'
```

## Color unions

| Type | Contents |
| --- | --- |
| `CSSNamedColor` | All 147 CSS named colors (level 4): `'red' \| 'aliceblue' \| ...`. |
| `CSSSystemColor` | Theme-aware system colors: `'Canvas' \| 'CanvasText' \| 'LinkText' \| ...`. |
| `CSSSpecialColor` | `'transparent' \| 'currentColor'`. |
| `CSSColor` | Union of all of the above plus `` `#${string}` ``, `rgb(...)`, `rgba(...)`, `hsl(...)`, `hsla(...)`, `oklch(...)`, `color(...)`. |

```ts
const accent: CSSColor = 'rebeccapurple'
const fg:     CSSColor = '#1a1a1a'
```

## Lengths

```ts
type CSSLengthUnit = 'px' | 'em' | 'rem' | '%' | 'vh' | 'vw' | 'ch' | 'pt' | 'svh' | 'dvw' | ...
type CSSLength = `${number}${CSSLengthUnit}` | '0' | `calc(${string})`
```

```ts
const gap: CSSLength = '1.5rem'
const x:   CSSLength = '0'
const y:   CSSLength = 'calc(100% - 2px)'
```

## CSS variables

```ts
type CSSVar<Name extends string = string>        = `var(--${Name})` | `var(--${Name}, ${string})`
type CSSCustomProp<Name extends string = string> = `--${Name}`
```

```ts
const fg: CSSVar<'fg'>     = 'var(--fg)'
const id: CSSCustomProp    = '--theme'
```
